# Benchmarks

Each benchmark reproduces a published result with the library, in its own folder. A folder holds a `README.md`, the paper's
equations (`Reference.wl`), the library pipeline (`Pipeline.wl`), the comparisons (`Checks.wl`), a headless driver (`run.wl`,
exit 0 = all pass) and a readable notebook generated by `makeNotebook.wl`. Each benchmark has a suite hook in `tests/acceptance/`.

| Benchmark | Reference | What it tests | Status |
|---|---|---|---|
| [KuramotoSivashinsky](KuramotoSivashinsky/README.md) | Gosteva, Wschebor, Canet, arXiv:2607.15784 (2026), Eqs. (34)–(37) | DE flows of ν, τ, D, ζ in d = 1, including Γ⁽¹¹⁾ at p⁴ (the n = 2 projection), the r‴ cancellation and the time-reversal identities | 9/9 exact |
| [KPZLO](KPZLO/README.md) | BMWflow `notes/LO_flow_equations.tex`, `kpz_notation.tex` (Kloss, Canet, Wschebor 2012, LO) | LO pipeline: flows of f_D(p), f_ν(p) at generic p (two pole families), η system from f(0) = 1, linear part at fixed p/k, ∂s g, symbolic d | 8/8 exact |

KPZ at lowest order (Canet's Eq. 20) is checked in `tests/acceptance/KPZ.wl` and `KPZAdimensional.wl`. It predates this folder.
