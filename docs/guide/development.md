# Development

## Tests

```
math -script tests/runTests.wl                          # unit + acceptance, ~6 min; exit code 0 means every test passed
math -script tests/runTests.wl --only DimensionsTest    # only the test files whose name contains DimensionsTest
math -script tests/runTests.wl --verbose                # also print the cards and FAIL blocks
```

Tests that need `julia` or FlowRG (`FLOWRG_PATH`) print SKIP when those are missing; `--require-julia` turns a SKIP into a
failure. `--require-python` does the same for the tests that need python3 and NumPy.

## Examples

`examples/ShallowWaterDE4plus.nb`, `examples/KPZ.nb` and `examples/KPZLO.nb` are generated by `examples/makeNotebooks.wl`. Edit
the cells there and regenerate. To check that a notebook runs without a front end:

```
math -script examples/runNotebook.wl examples/KPZ.nb                  # ~10 s
math -script examples/runNotebook.wl examples/KPZLO.nb                # ~10 s
math -script examples/runNotebook.wl examples/ShallowWaterDE4plus.nb  # ~2.5 min
```

## Benchmarks

Each folder in [benchmarks/](../../benchmarks/README.md) reproduces a published result. Run one with
`math -script benchmarks/<Name>/run.wl` (exit 0 = all pass).

## Lessons

One teaching notebook per module ([lessons/](../../lessons/README.md)). Edit `lessons/src/NN-Name.md`, then build with
`math -script lessons/makeLessons.wl`.

## Documentation

- Markdown is the source. GitHub renders it; a claude.ai artifact renders the same files as one site.
- `docs/reference/` is generated from the `::usage` strings: never edit it. Edit the usage string in `Kernel/*.wl`, then run
  `python3 tools/docgen.py reference`. The git pre-commit hook does this for you (enable it once per clone:
  `git config core.hooksPath .githooks`).
- `python3 tools/docgen.py check` fails when the reference is stale or a relative link is broken. GitHub Actions runs it on
  every push (`.github/workflows/docs.yml`).
- `python3 tools/docgen.py html OUT.html` writes the site as one HTML file.
- The other pages (this guide, [status](../STATUS.md), [modules](../MODULES.md)) are written by hand or by Claude Code.
